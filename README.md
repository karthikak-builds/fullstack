## 🚀 How to Run

### HTML Files

Open any `.html` file directly in a web browser.

### Node.js Applications

```bash
npm install
node servernode.js
```

### MongoDB Projects

1. Install MongoDB.
2. Start the MongoDB service.
3. Update the connection string if required.
4. Run:

```bash
node mongodbexpress.js
```
